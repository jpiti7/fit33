# Sprint v1.2.1 — PWA instalable en iPhone

## Objetivo

Preparar Fit33 para instalarse desde Safari en la pantalla de inicio de un iPhone.

## Incluye

- Manifiesto web nativo de Next.js.
- Iconos F33 de 180, 192 y 512 píxeles.
- Icono maskable.
- Metadatos Apple Web App.
- Viewport compatible con zonas seguras del iPhone.
- Página `/instalar` con instrucciones específicas para Safari.
- Acceso a la instalación desde Perfil.
- Apertura en modo standalone después de instalarse.

## Limitaciones

- La instalación final requiere desplegar Fit33 mediante HTTPS.
- El funcionamiento sin conexión se implementará en el sprint v1.2.2.
- Las notificaciones se incorporarán en una versión posterior.
