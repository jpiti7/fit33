# Roadmap de Fit33

## Visión

Fit33 será una aplicación completa de entrenamiento, nutrición y seguimiento corporal, con recomendaciones inteligentes basadas en los datos reales del usuario.

---

## Milestone 1 — Base del producto

Estado: completado

### Incluye

- Next.js.
- TypeScript.
- Tailwind CSS.
- Supabase.
- Autenticación.
- RLS.
- Dashboard.
- Registro de peso.
- Historial.
- Gráficas.
- Arquitectura modular.
- Infraestructura de calidad.
